### Alternative: Commercial License

If you plan to provide access to external partners or customers:

- Create a **commercial license agreement**
- Define usage rights and restrictions
- Include support and maintenance terms
- Specify liability and indemnification

### For Open Source Components

If any components will be open sourced:

- Use **Apache 2.0** for permissive licensing
- Use **MIT** for simple permissive licensing
- Use **AGPL** for copyleft with network use
- Clearly separate from proprietary code

### Legal Review

**Important**: This is a recommendation only. Consult with legal counsel to:

1. Ensure compliance with local laws
2. Protect intellectual property
3. Define liability limitations
4. Address third-party dependencies
5. Create appropriate commercial agreements

### Third-Party Dependencies

Review all third-party dependencies for license compatibility:

- Open source libraries
- NPM packages
- Python packages
- AI models and datasets
- External APIs and services
